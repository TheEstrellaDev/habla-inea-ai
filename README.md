# 💬 HablaINEA AI

Asistente conversacional y pedagógico impulsado por Inteligencia Artificial, diseñado para facilitar la educación primaria en adultos mayores a través de contenidos del INEA.

## 🛡️ Características
* **Interacción adaptada:** Lenguaje sencillo, paciente y empático.
* **Seguridad:** Arquitectura modular enfocada en la protección de datos y el uso de fuentes públicas.
